# 栖城 · Riverlight — 项目需求与重做方案

最后更新：2026-10-13。此文件是后续开发、验收与扩展的共同依据。

工作入口为根目录 `AGENTS.md`。每次开始或恢复工作按其顺序阅读规范和 GitHub 当前任务；新增需求先记录，再实现。当前代码为集成原型，不能把类别数量或自动测试通过当作完整体验已交付。

## 已确认的产品方向

- 桌面浏览器优先的 Three.js 城市建造沙盒，不限资金，无强制经营压力。
- 用户可自由建造、编辑、保存城市，也可关闭界面观赏城市。
- 画面融合「绿意丰富、温暖安静的河畔城市」与「有密度、夜景丰富的现代都市」。统一精致卡通/微缩美术，重视光影、沉浸、放松与氛围。
- Pocket City 提供建造体验参考，Cities: Skylines 提供道路、桥梁与城市空间参考；不追求同等规模的经济/人口模拟。
- 用户已授权保存本方案后直接重做，不需要逐项再次确认。
- 开发查阅会话技能目录中的 `threejs-*` 对应 SKILL.md；本机位置只在本地解析，不写入公开仓库。

## 优先级与画面标杆

画面协调、操作可靠、氛围连贯、存档可靠优先于模型数量和模拟复杂度。

性能验收以游戏电脑为主要目标，偏重画面质量；高画质优先保证模型、材质、灯光、反射与氛围的协调，同时保持建造、镜头和保存操作顺畅。具体硬件、分辨率、帧时间与城市活动预算由固定场景实测确定，不从设备类别推定已达标。

标杆场景：雨后黄昏的河畔街区，湿路面与水面反射暖色商店和桥梁灯光，公交驶过桥面，绿树/秋树随风摆动，远处现代楼群形成天际线。用户既可继续修建，也可隐藏界面静静观赏。

### 用户最新确认的整改要求

- **全套 Blender 资产**：不仅商场，住宅、公寓、其他商业建筑、公共建筑、公园和游乐园等场所都要在 Blender 中建模。通过 Blender MCP 制作并保留源文件；类别必须有独立结构和识别特征。
- **建筑不是改色的盒子**：商场有店面、中庭与出入口；游乐园有独立游乐设施与动画；住宅、学校、图书馆、美术馆等有符合用途的轮廓、立面、屋顶和室外空间。
- **更细的建造尺度**：不同建筑占地大小和长宽比例不同，允许更细网格与错位排布。当前实施尺度为 2 米细格，主路网单元保留 4 米；界面须清楚显示实际占地。
- **城市不能处处正方形**：道路要有连续转角与连接，河流要有自然弯曲、宽窄变化及精心安排的河岸；不能只把街道、建筑和水体摆进重复大方块。
- **繁华与景色共同成立**：形成沿街店面、紧凑住宅、天际线、公共目的地、游乐区和连续滨水空间。通过空间密度、层次、街景与活动营造城市感，不只增加模型数量。
- **清理无意义的外围树群**：树木用于行道树、公园、庭院和水岸景观，避免用随机树林填补构图空白。
- **重做夜间表达**：有选择地亮窗，灯光有冷暖、明暗和用途区别；避免整面玻璃均匀发光。兼顾店招、街灯、设施灯与地面、水面反射。
- **自动路人系统**：先确保连续人行道，再自动生成路人。沿街、过街、滨水步道与公共场所之间应有可走的连接；路人应行走和停留，不能只在原地摆动，更不能通过手动摆放行人交付。
- **进度必须持续维护**：需求和系统标准维护在文档，任务、已知缺陷与验证证据维护在 GitHub；每次工作先读取，以免中断后重复或遗漏。
- **分系统、分阶段推进**：明确依赖、功能边界和阶段出口；先小场景验证，再集成，不同时堆所有功能。带编号待办和固定验收场景是每项工作的入口。
- **模型质量与结构变体**：现有 Blender 模型还不够精细、多样；先制作高质量代表街区，统一比例、细节、材质、LOD 和画风，再扩充全库。
- **任意角度建筑**：角度输入/吸附与自由旋转，配套真实占地、入口、预览、选择、移动、历史及存档；不能只转动模型外观。
- **可信交通与生活**：车道寻路、跟车、转弯减速、停车排队、红绿灯及路口冲突控制；行人有目的地、等待、过街、停留和避让，共享信号规则。
- **消除跨系统穿帮**：船只须满足桥底和桥墩净空，桥上车人高度连续；露天行人在雨天撑伞或避雨，遮蔽处/停雨后收伞。不是仅新增几个装饰动画。

## 世界与扩展

- 不把 64×64 作为地图硬上限。分区数据与场景显示分离，按需创建/释放显示资源。
- 以分区方式扩大建造范围；未改动地形可确定性生成，用户编辑持续保存。
- 近景完整细节、中远景简化显示；全城总览单独控制细节预算。
- 重复物体批量绘制、材质和几何共享；天气粒子围绕当前观察区域。
- 道路跨分区保持连接；世界数据表达地面、水面与桥面高度。
- 实際容量以密度、活动数量、设备和画质压力测试为准，不承诺无限满细节世界。

## 建造与编辑

- 分类目录：住宅、商业/高楼、公共建筑、公园、道路桥梁、自然和街景装饰。
- 目录拖入场景或点击后放置；预览、细格吸附、任意角度旋转与占地冲突反馈。默认角度吸附建议 15°，同时提供数值和自由角度；当前仅有 90° 旋转，属于待升级原型。
- 细分网格必须贯穿放置、预览、旋转、碰撞、选择、移动、撤销及存档；不能仅缩小画出来的网格。
- 点击建筑选择、移动、旋转、复制、删除；连续放置、撤销与重做。
- 道路连续绘制并更新路口；桥梁与两岸道路连接，车辆沿有效路线通行。
- 道路从中心线生成直线/曲线、转角、车道、人行道与路口连接；车人沿实际可见表面移动。连续曲线道路纳入 R3，现有圆角网格原型不算完成；立交、隧道和复杂多层路网属于后续扩展。
- 树木笔刷、配色、区域复制与街区模板是创作工具的扩展方向。
- 建筑具有稳定素材 ID、占地、类别、视觉变体等独立配置，便于添加内容。

## 自然与城市内容

- 河流、水岸、桥梁、滨水步道、绿地与公园形成骨架。
- 独栋住宅、公寓、沿街商业、办公楼、地标及公共设施形成高低层次。
- 路灯、长椅、店招、花坛、围栏等提供尺度细节。
- 轿车、出租车、货车、公交、船只；后续扩展电车和更复杂站点。
- 车辆沿路通行，行人活动与场所对应；不以完整市民经济模拟作为首版要求。
- 自动行人数量受性能预算控制；路网编辑后更新步行连接，避免穿楼、踏水、在断路间瞬移。适当提供走路摆臂、步态、短暂停留等近景细节。
- 首版包括目的地寻路、车辆跟车/停车、红绿灯相位与冲突控制、行人信号过街；复杂变道、自适应信号和公交运营在后续迭代。
- 桥梁设计同时满足桥下船舶净空、桥墩横向通航空间和桥上引道坡度；不可通航时船安全等待或改道，不穿模、不缩小模型掩盖问题。

## 环境与氛围

- 四季：植被颜色和疏密变化、春花、秋叶、冬季积雪。
- 天气：晴、多云、雨、雪、雾；时间、天气、季节可独立调整并平滑变化。
- 24 小时昼夜、时间暂停/速度调节；天空、太阳、阴影、窗户与路灯联动。
- 风影响树冠和粒子；落叶来源集中在植被附近。
- 雨中地面逐渐变湿、局部积水、雨滴涟漪；雨后逐渐干燥。
- 人物与视觉共用降雨状态：露天撑伞/寻找可达遮蔽，室内或停雨后收伞；转变有过渡，避免反复开合。
- 水面、湿路、玻璃采用不同的反射强度和清晰度；按画质控制成本。
- 积雪与融化有过渡，雨雪粒子循环而非整体移出地图。
- 氛围预设：河畔晴日、秋日午后、雨夜街角、雪中小镇等。
- 环境声、天气声、城市声与背景音乐独立调节；音频在用户操作后启动。

## 相机与界面

- 建造视角与自由观察；鼠标缩放、旋转、平移，方向键/WASD 移动。
- C 或相机按钮切换；Home 返回全景；R 旋转；Esc 取消；Ctrl/Cmd+Z 撤销。
- 以场景为主体，简洁目录、环境面板、编辑工具和明确状态反馈。
- 隐藏界面、缓慢环绕、截图、保存镜头位置；跟随车辆和路线巡游可持续扩展。
- 首次进入可编辑示范城市；也能新建空白城市。

## 数据与可靠性

- 多城市本地存档、自动保存、手动保存、文件导入导出。
- 存档有格式版本、输入校验与升级空间；显示资源卸载不等于删除城市。
- 窗口调整、快速切换天气、取消移动、撤销拆建和跨分区操作应保持一致。
- 不伪造人口、经济或服务覆盖数据。状态栏显示实际统计。
- 外部素材记录来源与许可；原创程序生成模型明确标注。
- 公开 README 面向初次访问项目的人，介绍产品、真实可用功能、本地运行、操作与保存方式；开发交接、代理约定和未确认讨论不作为首页内容。

## 验收场景

- 从空白城市铺路、过河建桥、放住宅/高楼/公园并编辑；占地不重叠。
- 移动失败可取消恢复，撤销重做保持道路/建筑/统计一致。
- 扩区后能继续建造；离开再返回可恢复区域显示和编辑内容。
- 存档刷新恢复；导出再导入保持城市布局及环境设置。
- 同一街区在晴天、黄昏、雨夜、秋季、雪景下有明确且协调的差异。
- 车辆沿连通道路与桥梁行驶；道路修改后更新路径。
- 车辆跟车排队、转弯减速、按灯色和路口权限通行；行人等灯并安全清空过街区，灯色与规则一致。
- 建筑以 15°、30°、45° 和自由角度放置后，碰撞、入口、移动、撤销及保存仍一致。
- 最大测试船型经过桥下和桥墩之间不穿模，桥上车人与引桥高度连续；雨天人物撑伞/避雨、停雨收伞可重复观察。
- 小型住宅与大型场所有不同占地，半格错位可放置、移动、旋转和往返保存，模型不超出其声明占地。
- 连续转角无方块断口；新河道弯曲、宽窄有变化；加载旧城不改变其原河道。
- 不需要摆放行人即可看到路人沿人行道行走，在有效连接处过街、进入公共空间；拆改道路后不会继续走过已消失的路段。
- 商场、学校、住宅、图书馆、美术馆、游乐园可由造型识别；游乐设施动画、窗灯和夜间氛围在实际浏览器中可检查。
- 缩放、全景、隐藏界面和截图可正常使用。
- 启动/生产构建无错误；自动测试覆盖占地、历史、道路与存档等关键数据逻辑。
