# 素材与依赖说明

更新：2026-10-13。

当前资产属于集成原型，导出数量不代表精细度与多样性通过验收。升级标准见 [SYSTEMS.md](SYSTEMS.md) 的 S08，先执行 R1 六类代表样板，再按 GitHub 中 ASSET 系列任务精修全库。

## 本次重做使用的内容

- 正式目录中的 34 类建筑及场所资产已通过 Blender MCP 原创建模，包含 8 类住宅、9 类商业、5 类公共建筑、5 类公园/场所、7 类街景装饰。每类有近景、远景两个 GLB，共 68 个文件，位于 `public/models/`。
- 可编辑源文件：`assets/blender/riverlight-city-library.blend`（住宅、商业、公共、景观等库）、`assets/blender/riverlight-shopping-gallery.blend`（商场）。既有 Blender 场景保留，建模使用独立场景。
- 建模/导出脚本：`scripts/blender/build_city_assets.py`、`scripts/blender/build_mall.py`。`assets/catalog-reference.json` 记录建模时原始尺度，运行时可按目录占地适配；修改时需保持原始尺度依据一致。
- 建模脚本不硬编码开发者本机路径：优先使用本地 `RIVERLIGHT_PROJECT_ROOT` 变量，其次从脚本、当前工作目录或已保存 BLEND 的位置向上查找项目。无法识别时明确报错；环境变量的实际值不提交仓库。
- 动画资产包括商场旋转门、游乐园摩天轮及座舱、旋转木马、喷泉动态部件。实际浏览器动画与远景策略仍需按 GitHub 中关联任务完成最终验收。
- 本轮修正美术馆、诊所的外墙材质语义并重新导出近远景 GLB；可编辑城市库源文件同步保存。该修复不等同于新一轮造型精修完成。
- `src/asset-loader.js` 加载 GLB，`src/models.js` 保留原材质、合批静态几何并保留动态部件；`src/architecture.js` 提供加载失败时的备用模型。
- 道路、桥梁与连接几何由 `src/roads.js` 在运行时生成；河岸地形与部分沿岸家具由 `src/world.js`、`src/models.js` 生成。车辆、船只、人物目前仍是运行时原创几何，后续可扩展 Blender 资产。
- 桥梁附属结构沿运行时桥面采样布置。林间木桥用交叉木栏，石栏桥用带柱帽的石柱，钢梁桥用桥边纵梁，钢拱桥用双侧钢拱、吊杆和高位横梁。远景减少重复构件，保留桥型轮廓。
- 天空、水面法线、天气粒子、积水遮罩：代码或 Canvas 生成，无第三方图片下载。
- 背景音景与风雨声：`src/audio.js` 通过 Web Audio 合成，无第三方音乐录音。
- 界面图标：`src/icons.js` 内的简单 SVG 路径；标识及 favicon 为本项目制作。
- 字体：使用设备自带系统字体，未分发字体文件。

## R1 街区样板

[河光小街画风参考](ART_DIRECTION.md) 记录材质色板、比例与 T06 固定镜头对照，供六类样板统一调校。

住宅与面包房样板源为 `assets/blender/riverlight-street-samples.blend`，制作脚本为 `scripts/blender/build_street_samples.py`。公共建筑图书馆样板源为 `assets/blender/riverlight-library-sample.blend`，制作脚本为 `scripts/blender/build_library_sample.py`；仅写入本次创建的场景，不覆盖用户已打开的场景或旧城市资产库。

图书馆保持 `library` ID 和既有占地适配，包含高低阅览楼、书架展示开间、木格栅、内凹入口、雨棚、座椅和花池。本轮将两级模型的主体石墙标为 `Wall`，使保存的立面色在远近切换时一致生效。

高层样板白榆办公楼保留 `office` ID，源文件为 `assets/blender/riverlight-office-sample.blend`，制作脚本为 `scripts/blender/build_office_sample.py`。内凹大堂与低翼露台形成两级退台，主体以石材竖肋、转角窗和后退的顶部收口区分。雨夜按固定分布点亮部分办公间、招牌和入口檐下灯。近远景共用地面、边界和两处锚点。

口袋公园 `park` 与桥旁码头 `pier` 保留原 ID 和 8 × 8 米占地，源文件为 `assets/blender/riverlight-landscape-samples.blend` 的两个独立场景，制作脚本为 `scripts/blender/build_landscape_samples.py`。公园的步道绕过花台和树下座椅，通往有木屏和檐灯的休息亭。桥旁码头由岸端坡面、架空木栈台和侧置候船亭组成，中间保留登船通道。码头 `+Z` 朝岸，T06 在西岸旋转 270°，使入口位于现有滨水步道上。船舶停靠、桥船净空和遮蔽行为由对应系统验收。

六类样板在 T06 v3 同时加载。高层在原阳光公寓的展示位置，公园入口经两格小径接入原步道，码头位于桥南西岸。沿用三个固定镜头，「街区」能看完整办公楼退台和滨水关系。已有 T06 存档可用 `?scene=T06&resume=1` 续用，重置场景会先备份编辑，再加载 v3。整组画面由用户确认。

### ART-02 模型契约

- **单位与轴向。** Blender 以米建模，地块中心地面为 `(0, 0, 0)`，`+Z` 朝上，正面朝 `−Y`。导出后 Three.js 的 `+Y` 朝上、`+Z` 朝街。近远模型共用原点、轴向和外轮廓。
- **占地。** `assets/catalog-reference.json` 记录建模用的原始地块尺寸，每格 4 米。运行时把横向与纵深按目录地块和原始地块的比率缩放，高度保持米制。旧城的 `lot` 在实例摆放时再适配原地块。摆放和碰撞仍使用存档及目录中的占地。
- **入口与屋檐。** 用 Empty 命名 `<资产 ID>_Entrance` 和 `<资产 ID>_Shelter`，分别放在入口外可接步道的落脚点和屋檐下的可站立点。两级 GLB 都保留锚点。模板的 `userData.anchors.entrance/shelter` 是已适配目录地块、相对模型原点的米制坐标。步行图对入口应用实例位姿与旧占地比例，屋檐锚点供避雨任务使用。
- **公园檐灯。** `park_Light` Empty 位于灯罩下方，两级 GLB 均提供同一位置。环境系统从模板读取灯位，应用放置旋转和占地比例，夜间在现有局部光源预算内照亮亭子及附近小径。
- **材质。** 使用 `RL_<语义>_<名称>`。其中 `Wall` 用于可换色墙面，`Glass` 用于窗玻璃，`WindowWarm`、`WindowSoft`、`Sign`、`Festival` 和 `Light` 用于随时间点亮的表面。保留 glTF 的基础色、粗糙度、金属度、各纹理及其 UV。换色只调墙面底色，玻璃塔沿用玻璃立面换色，叶片、积雪和昼夜效果继续按语义控制。可搬运的纹理随 GLB 嵌入。
- **动画。** 可动子树用稳定、唯一的节点名和 `riverlight_dynamic` 标记，静态合批时保留动画轴心。近景导出 glTF 动画，远景保留可辨认的静态轮廓。游乐园座舱与商场旋转门已有模型级回归。
- **LOD。** 导出 `<ID>.glb` 与 `<ID>_lod.glb`，远景优先去掉倒角、小构件和重复细节。两级共用立面色和锚点。远景文件加载失败时使用近景模型。分区选择根据相机距离及区块中心与焦点的距离，T06 的「全景」构图仍可能显示近景模型。

## 素材获取与制作约定

- 材质不能过于卡通化；木、石、墙面、沥青、玻璃和金属须保留可辨认的质感，细节尺度与整体微缩画面协调，通过样板确认。
- 声音素材现阶段由用户搜索和提供。需要特定音效时，说明场景、触发方式、时长、是否循环、变体和空间表现，再向用户询问；接入时记录具体来源与许可。
- 声音风格按场景和氛围选择，不统一限定为自然柔和。音频制作软件与 MCP 方案留待后续决定；当前合成音景仍是原型。
