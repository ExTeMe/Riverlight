## 数据、尺度与兼容性

城市数据独立于 Three.js 显示资源。离开分区只释放显示对象，返回时从城市数据重建。起始范围 128×128 个 4 米逻辑单位；细格为 2 米，界面须区别“逻辑地图范围”和“建筑细格占地”。每次扩区向四边增加 16 个逻辑单位。

存档版本 2 增加 `terrain` 区分 `meander` 和 `legacy`。版本 1 恢复时记录旧建筑 `lot` 尺寸并保留旧水系；已通过自动迁移检查，完整浏览器编辑回归仍待做。坐标支持 0.5 逻辑单位，道路/桥/小径仍要求整数逻辑坐标；旋转依旧为 90 度。Blender 模型的原始尺寸依据保存在 `assets/catalog-reference.json`，不要无意覆盖。目标米制契约、任意角度、曲线道路与桥高格式尚未实施。

保护上限为 8192×8192 逻辑单位、100,000 个物件，不等于满密度可见时的帧率承诺。全部城市数据仍驻留内存，自动存档仍为整城快照；大规模编辑有整批显示/交通重建成本。后续优先做分区增量更新、Worker 存档、按需资产加载和真实设备测试。

已通过的检查包含基础占地/历史/路网/扩区/序列化、细格及旧档迁移、34 类 GLB 及近远版本解析、LOD/配色、部分导入动画、四向圆角法线和步行连接、路人移动与拆路清空、4,500+ 建筑数据场景分区卸载再恢复。后者只验证数据及显示资源生命周期，不是 GPU 性能证明；人物测试没有验证目标寻路、红绿灯、避让或天气行为。

## 代码入口

资源加载使用 Vite 的 `import.meta.env.BASE_URL`：GLTFLoader 的模型目录随构建基路径变化，根目录本地运行与网站子目录均可用。2026-10-10 已验证子目录生产构建和浏览器启动；未调整城市美术或模拟行为。

| 文件 | 职责 |
| --- | --- |
| `src/catalog.js` | 稳定目录 ID、原尺寸与新占地、细格尺度 |
| `src/core.js` | 城市数据、占地/分区索引、历史、路网、新旧水系、版本迁移、示范城 |
| `src/asset-loader.js` | 并发载入 Blender 近远 GLB |
| `src/models.js` | 共享材质、GLB 静态合批/动态子树、材质季节变化、模板 |
| `src/architecture.js` | 资产加载失败时的备用造型 |
| `src/roads.js` | 道路、圆弧转角、人行道边缘、斑马线、桥梁几何 |
| `src/world.js` | 分区、地形、模型实例、选择/预览、车辆/船与行人模块协调 |
| `src/walk-network.js` | 从现有道路、路径和水岸推算步行图，连接入口，随机邻边路线原型 |
| `src/pedestrians.js` | 自动人物实例、步行更新、步态、粗略车辆等待与资源释放 |
| `src/environment.js` | 天空、水、光、昼夜、四季、天气、落叶 |
| `src/puddles.js` / `src/ambient-occlusion.js` | 局部积水平面反射 / 环境遮蔽 |
| `src/main.js` | 输入、相机、渲染、编辑协调、保存 |
| `src/ui.js` / `src/style.css` | 中文界面、缩略图、面板和响应式布局 |
| `src/storage.js` / `src/audio.js` | 本地存档 / 合成音景 |
| `scripts/blender/` | Blender 原创模型与导出脚本 |

当前玻璃是标准材质反射，水和积水使用平面反射；流畅档关闭积水反射、环境遮蔽和辉光。积雪以材质渐变表现，没有物理厚度。外圈随机背景树已移除；目录内树木仍可编辑。行人路径目前由步行模块推算，不是目标中的道路统一几何源；人物重建会重置活动。未来功能不能写成已交付，长期阶段标准见 DEVELOPMENT_PLAN，具体任务直接在 GitHub 查询。
