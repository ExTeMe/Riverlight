# Riverlight 单人开发自动化

操作依据为 [GIT_WORKFLOW](../docs/GIT_WORKFLOW.md)。

旧多人管理工作流已退役，不执行认领、资源冲突仲裁、审查登记、验收准备和定时看板同步。历史实现暂留供历史记录解析与迁移参考，但正式执行入口不再调用它，也不再要求 Project 凭据。

站点工作流继续按改动运行隐私、文档与构建检查，更新已授权的 dev 预览。仓库设置保留 PR、check、防删除和防强推；dev 移除 collaboration 要求，main 发布权限不变。

验证需覆盖退役入口不会调用 GitHub API，以及 dev 规则不再生成多人检查。远端规则与默认分支入口需另行回读，不能用本地配置证明已上线。
