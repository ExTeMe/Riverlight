# Riverlight 首批建筑样板计划

2026-11-20 · RPI Plan

首批交付一座住宅和一座市集，放进同一段已有河岸街区。用户在游戏的普通建造镜头中判断两栋的用途、建筑完成度和与环境的关系，再用近景看结构、入口与内部。 [用户确认](../REQUEST.md) · [建筑标准](../../../docs/ART_DIRECTION.md#建筑设计规范)

## 1. 已完成 · 范围与技术起点

- [x] 用户选定住宅与市集，首批验不同用途的共存。研究中两种住宅的方案保留作以后同类多样性验证。 [研究](../research/RESEARCH.md)
- [x] 在 `T04-WEST` v2 的内存副本，以现有地块规则试放 9.5 × 12 米住宅地块和 14.5 × 11.5 米市集地块。代理入口分别可达指定西岸过街北端，南端可达西岸及贴岸平台。检查排除了其他过街边。两块之间留下 3.25 米，桥结构及 218 段既有岸道保留。 [试放数据](eng.md)

## 2. 已完成 · 两栋首稿与同场关系

- [x] 两栋已出平剖面、场地布置和独立可编辑 Blender 体量。住宅有入户、窗边、生活区、洗手间、楼梯与后卧室。市集有高屋盖、3.50 米主走道、三类摊位、等候及侧向服务。
- [x] 在实际 Chrome 载入两套 GLB。固定场地拍摄街区、两栋同框和低视点；以屋面、开口、接地和步行图复核，已调整住宅凸窗和屋面构件的空间关系。 [设计要求](pm.md) · [取景与评审](ux.md) · [实施证据](../implement/IMPLEMENT.md)

## 3. 已完成 · 首稿 Blender 细化、导出与游戏内落位

依赖第 2 阶段的平剖面和体量成立。

- [x] 住宅细化双向采光的阅读湾、门廊、楼层衔接和厨房。市集细化屋架、三类工作摊面、装卸侧、座椅和后场。两栋均有可编辑 BLEND、近远 GLB、打包材质、入口、遮蔽点及独立分区灯位。
- [x] 开发场景 `WEST-BUILDINGS` 已接入两套资源并开放建造。核对近远包围盒、锚点、颜色、实际灯位和净空，验证桥与建筑互换建造顺序、23° 摆放、撤销重做、隔离保存重载与旧档回读。 [技术契约与回归](eng.md) · [实测记录](../implement/IMPLEMENT.md)

## 4. 返工中 · 浏览器视觉验收

依赖住宅和市集均达到可评完成度。2026-11-21 用户否定市集的尺寸与内部组织，先按 4.1 重做市集，原实拍与技术验证保留为对照。 [反馈](../REQUEST.md) · [返工研究](../research/RESEARCH.md#2026-11-21--市集退回设计)

- [ ] 在街区默认视角交付两栋同框的白天图。同构图复拍黄昏、雨夜，加上住宅和市集各一张能看到空间进深的近景。检查不同用途、共用街道的尺度、住宅一端的私密感、市集一端的公共前场、与岸线的过渡。另存去色对照、建造证据和客观检查结果。 [截图与用户评审](ux.md)
- [ ] 用户在实际游戏画面确认两栋的视觉质量与邻接关系。记录需调整的是单体、悬挑或接地、场地关系、材质灯光还是镜头，再对同一构图复评相应项目。

### 4.1 市集退回设计

- [x] 对照旧市场低机位画面，确认旧直通走道、摊位进深与场地限制。试放 22 × 24 米地块并确认住宅通巷、桥与岸道可沿用。
- [x] 用可编辑模型、平面和实际浏览器检查采买双巷回游、河边熟食座席、后侧卸货备货。旧版和改稿同镜头对比，采集厅内、河侧、后场和截顶实景。通过主入口接线、实际放置、撤销重做。 [验收补充](pm.md#市集改稿) · [实施证据](../implement/IMPLEMENT.md#2026-11-21--市集空间改稿)
- [ ] 用户确认市集等级和空间组织后，将候选进入正式资源预算、独立远景、日夜验收和资产接入。室内出入口与活动依需求另验。
