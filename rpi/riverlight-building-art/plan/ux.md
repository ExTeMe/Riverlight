# 游戏内操作、取景与视觉评审

## 玩家怎么放置

1. 打开住宅与市集的独立开发场景，用原有地块工具放住宅。看入口建议和预览接线，选取街侧落点，留通巷。试一次关闭角度吸附后的自由旋转，核对模型、占地和门的位置一起转。
2. 在桥头一侧放市集，主入口对前场，保留现有过街和面向岸道的行走线。检查装卸侧和停留空间落在步行主线旁。普通入口无法接到步道时显示现有入口反馈，修改地块或铺装后观察恢复。
3. 打开实际步行图，从住宅门、市集入口分别核对路径。关闭叠图回到普通画面，保存并刷新。用原有撤销、重做和读档入口验证。沿用控件的可见标签、键盘取消和文字错误提示。

## 固定观察

| 视图 | 条件与用途 |
| --- | --- |
| 街区默认镜头 | 39° 透视，起始参考 `(-26,37,63) → (-37,0,7)`。同图包含住宅、通巷、市集、桥头和岸线。固定构图复拍白天 13:00、黄昏 17:30 与雨夜 20:00。保留人物尺度和真实活动。 |
| 住宅近景 | 从人行道斜看门廊、开口、窗边和庭院。辅以侧向或室内镜头确认楼梯、上下层和私密遮挡。室内辅图用来说明结构。 |
| 市集近景 | 从前场朝主走道，再从侧巷看装卸侧。看主屋盖怎样支撑，摊位是否各有功能，灯下能看到经营空间而且通道人流可走。 |
| 灰材质与 LOD | 用同一个街区镜头比较同一组模型的轮廓、开口和深度。固定视向跨近远切换，重点看屋顶、柱、雨棚、灯位和入口。灰材质图单独标记，正式材质规定见资产契约。 |

提交实景前确认浏览器使用候选近远 GLB。正式灰度对照可作为诊断图片，主审图使用实际材质与游戏照明。保留一张关闭工具叠图的清晰街区主图，近景只补充能观察到的新内容。 [资产契约](../../../docs/ASSETS.md#art-02-模型契约)

## 用户确认点

先看街区画面里的两个问题。住宅和市集各自是什么样的建筑，是否看得出它们能和同一条街、桥头和岸边自然接上。再用近景和雨夜判断住家是否安静、市集入口是否看得懂、室内和材质是否有足够层次。反馈按画面中的建筑部位定位，以相同构图复拍改动。 [验收 A1–A5](pm.md)
