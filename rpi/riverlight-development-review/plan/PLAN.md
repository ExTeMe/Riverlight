# Riverlight 街岸衔接验证计划

2026-11-20 · RPI Plan

以 B 的沿街规划和 C 的滨水公共空间为两种可分别使用的建法。首个游戏内切片验证它们如何通过桥头前场自然接续，同时保留向其他街区和岸段延伸的可能。范围和验收见 [pm.md](pm.md)，操作和取景见 [ux.md](ux.md)，实现与验证见 [eng.md](eng.md)。

- [x] 沿街使用现有地块和选取流程，添加相邻道路给出的朝向建议。玩家可保持或改动该值，并保有两个不同面宽及通巷。
- [x] 前场接线、陆侧平台和缓坡由共享几何生成显示与步行图。两种建法可以独立使用；过街和岸道复用现有系统。缺失过街、受阻和恢复均已验证。
- [x] 确认两种建造顺序，分别删除平台、移除末栋建筑、撤销与重做，保存、刷新和导出回读后重新核对图与显示。拒绝进水、坡道不接地、占住沿岸通路的草稿。 [验收项 P1–P4](pm.md) · [流程与状态](ux.md) · [事务与存档](eng.md)
